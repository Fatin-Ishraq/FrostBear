# FrostBear 1.1.0 — Initial Release

The first public release of FrostBear for **Minecraft Java Edition 26.2**.

## Included in this release

- A custom **260-health FrostBear boss**
- Natural spawning in snowy and icy biomes
- FrostBear guardian encounters near igloos
- Polar-bear transformation using **Slowness** and **Weakness**
- Custom model, textures, animations, glowing eyes, and back crystals
- Roar, charge, frost-breath, chilling melee, and ice-spike attacks
- Custom sounds, particles, loot, and boss bar
- **Frozen Heart** with instant Heart of Winter activation
- **Glacial Core** crafting and repair material
- Craftable **Frostfang** weapon with an ice-spike wave ability
- Recipe-book, dedicated-server, and single-player support

## Requirements

- Minecraft **26.2**
- Fabric Loader **0.19.3 or newer**
- Fabric API
- Java **25**

This release has been tested successfully in-game and on a dedicated server.
