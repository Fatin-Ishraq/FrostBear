# FrostBear

![FrostBear banner](https://raw.githubusercontent.com/Fatin-Ishraq/FrostBear/main/screenshots/frostbear-banner.png)

FrostBear adds a powerful frozen polar-bear boss to Minecraft's coldest regions, complete with a custom model, animations, sounds, combat abilities, valuable loot, and new equipment.

## Features

- A formidable **260-health FrostBear boss**
- Natural spawning in snowy and icy biomes
- Special FrostBear encounters near igloos
- Custom roar, charge, frost-breath, and ice-spike attacks
- Glowing eyes, back crystals, and custom animations
- Unique sounds, particles, and boss bar
- Transform a polar bear by applying both **Slowness** and **Weakness**

## Frozen Heart

Right-click the Frozen Heart to instantly activate **Heart of Winter** without an eating animation.

It provides:

- Freeze immunity
- A freezing and slowing aura
- A short burst of regeneration
- A dramatic activation effect

## Frostfang

Craft Frostfang using:

```text
Glacial Core
Blue Ice
Stick
```

Frostfang is a powerful ice weapon that chills struck enemies. Right-click to erupt a wave of ice spikes across the ground.

## Requirements

- Minecraft Java Edition **26.2**
- Fabric Loader **0.19.3 or newer**
- Fabric API
- Java **25**

FrostBear supports both single-player and dedicated servers. All connecting players must have the mod and Fabric API installed.
